# LIHI SKIN STUDIO — בדיקת שילוב המותג

השם המקצועי עודכן לפי הבריף הנוכחי ל־**ליהי פרנס רפפורט**.

## הלוגו

- מקור מאושר: `LIHI Skin Studio Logo.png` בשורש הפרויקט. קובץ המקור לא משתנה.
- `public/brand/lihi-skin-studio.png`: הלוגו המלא עם שקיפות, ללא השוליים הגדולים של המקור. מופיע בכותרת בדסקטופ ובפוטר בכל הרוחבים.
- `public/brand/lihi-wordmark.png`: חיתוך של אותיות LIHI המקוריות בלבד. מופיע בכותרת עד רוחב 600 פיקסלים.
- נשמרו האותיות, היחסים והצבעים המקוריים. החיתוכים אינם כוללים ריטוש או צביעה מחדש. שניהם מוצגים עם `object-fit: contain`, ללא רקע, מסגרת או אפקט.
- הכותרת נשארת בגובה 88 פיקסלים בדסקטופ ו־68 במובייל. הלוגו המלא מוצג במסגרת תצוגה של 160 × 66; סימן LIHI במובייל במסגרת 110 × 35. בפוטר נשאר הלוגו המלא.
- הפוטר נשאר בהיר ולכן מוצגת הגרסה הצבעונית המקורית. לא הומצאה גרסה לבנה ללא קובץ מקור מאושר.
- לא נוסף לוגו לאזור הפתיחה. הפורטרט, הכותרת, הצבעים והאינטראקציות הקיימות נשמרו.

## עדכון מיתוג

הכותרת, הפוטר, פרטי העסק, טקסטי האודות, כותרת הדפדפן, תיאורי התמונות, favicon, Open Graph ו־Twitter עודכנו ל־LIHI SKIN STUDIO. תמונות המוצרים ותעודת ההכשרה האותנטיות לא שונו. שם חבילת הפרויקט עודכן גם הוא.

אייקוני הדפדפן מבוססים על סימן LIHI המקורי. תמונת השיתוף היא הלוגו המקורי על רקע השנהב הקיים, ללא טיפוגרפיה חדשה או אפקטים. לפני שיתוף ציבורי, לאחר אישור דומיין הייצור, יש להשלים כתובת מוחלטת לדומיין ב־`og:image` וב־`twitter:image` (כעת נתיבי המדיה יחסיים לאתר).

```sh
npm run brand:prepare
npm run build
npm run review:brand
npm run test:production
```

השינויים מיועדים לבדיקה מקומית בענף `brand/lihi-skin-studio`. אין לדחוף ל־main או להפעיל פריסה לפני אישור המשתמש.
