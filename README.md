# LIHI SKIN STUDIO — ליהי פרנס רפפורט

A complete Hebrew RTL skincare landing page, built with semantic HTML, modular JavaScript, CSS and Vite. No backend, database, tracking or external runtime services. The three supplied mockups guide the visual design; none of their photos, reviews or results are reused.

The approved LIHI SKIN STUDIO logo is integrated in the header and footer, with the original LIHI wordmark in the mobile header. See the [brand integration review and screenshots](docs/BRAND-REVIEW.md). Brand assets are already included in `public/brand/`; `npm run brand:prepare` regenerates them from the untouched approved PNG. No deployment is authorized for this branding update until user approval.

## Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

Open the printed localhost URL. In Windows PowerShell environments that block npm.ps1, use `npm.cmd` instead of `npm`.

```sh
npm run build
npm run preview
```

The production build is written to `dist/`. Nothing is deployed automatically.

## Deployment build settings

This project builds as a static Vite site. For the eventual Vercel import, use:

- Project root: repository root (`./`).
- Install command: `npm ci`.
- Build command: `npm run build`.
- Output directory: `dist`.
- Environment variables: none required.

The optimized media and local fonts are included in `public/`; media preparation is not required during deployment. Keep `package-lock.json` committed. This repository setup does not deploy the site.

## Content and assets

- `src/content.js`: business and contact details, treatment topics, about copy, reviews, FAQs, questionnaire choices.
- `src/media.js`: every image and video destination, dimensions, ratios, placeholder state and accessible descriptions.
- [Media replacement guide](docs/MEDIA-GUIDE.md): exact replacement workflow and destination table.
- [Generated asset manifest](docs/media-manifest.json): full machine-readable inventory, regenerated on build.
- `src/main.js`: reusable media renderer, page sections, and interactions.
- `src/styles.css`: responsive layouts, local fonts, design system and reduced-motion support.

All ten requested sections are implemented. Five supplied originals now appear in the hero/about portrait, certificate, clinic gallery and first before/after comparison. Optimized WebP copies are generated by `npm run media:prepare`; originals remain untouched, and before/after conversion is lossless. The other media slots remain designed placeholders. There are three independent before/after pairs, review slots without fabricated names or quotes, a keyboard and touch comparison control, review carousel, image/video modal, five FAQ accordions and a two-step questionnaire that prepares a WhatsApp message. The questionnaire never persists answers or sends them to a server. WhatsApp only receives the selections when the visitor chooses its link; the visitor sends the message themselves.

## Validation

With the dev server running and Google Chrome installed:

```sh
npm test
npm run test:production
```

Tests exercise actual browser interactions, touch controls, and seven responsive widths (320–1440px), check horizontal overflow and missing assets, and run axe WCAG A/AA checks at desktop, tablet and mobile widths. Screenshots and audit findings go to ignored `test-results/`. The production test starts and stops its own preview server on port 4173; run `npm run build` first. You can also target a running server with `TEST_URL`.
